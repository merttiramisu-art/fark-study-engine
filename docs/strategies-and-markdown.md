# Transparent Spacing Strategies & Markdown Notes

**FARK Study Engine v0.4.0** adds two pure, dependency-free modules to help educators, learners, and developers inspect how interval presets behave and turn everyday Markdown notes into portable flashcards.

## 1. Transparent Review Strategies (`fark-study-engine/strategies`)

Different courses, exam timelines, and study materials tolerate different spacing cadences. Rather than claiming a single black-box schedule is cognitively optimal for everyone, `./strategies` exposes three documented interval presets that share identical `0..6` box bounds and card validation with `reviewCard`:

| Strategy ID | `again` | `hard` | `good` intervals (boxes `1..6`) | Best suited for experimenting with |
| --- | --- | --- | --- | --- |
| `balanced` | 10 min | 6 hours | `1d · 3d · 7d · 14d · 30d · 60d` | Default FARK spacing |
| `gentle` | 10 min | 4 hours | `1d · 2d · 4d · 7d · 14d · 30d` | Denser or unfamiliar concepts |
| `intensive` | 5 min | 2 hours | `0.5d · 1d · 2d · 4d · 7d · 14d` | Compressed short-horizon prep |

```js
import { createCard } from 'fark-study-engine';
import { reviewCardWithStrategy, compareStrategies } from 'fark-study-engine/strategies';

const card = createCard({ id: 'bio-1', topic: 'Biology', question: 'ATP role?', answer: 'Energy carrier' });
const next = reviewCardWithStrategy(card, 'good', '2026-11-14T09:00:00Z', { strategy: 'gentle' });

const diff = compareStrategies(['good', 'good', 'again', 'good', 'easy'], {
  startAt: '2026-11-14T09:00:00Z'
});
console.log(diff.strategies.map(s => [s.strategy, s.totalSpanDays, s.finalIntervalDays]));
```

**Important caveat:** All presets are deterministic arithmetic rules, **not** adaptive AI or personalized memory-decay models. Changing strategy never rewrites past reviews; it only schedules the next `dueAt` timestamp when you grade a card.

## 2. Markdown Study Sheets (`fark-study-engine/markdown`)

Export any validated deck as clean, printable GitHub-Flavored Markdown grouped alphabetically by topic, or parse everyday Q&A notes back into unreviewed FARK cards:

```js
import { exportStudyMarkdown, importStudyMarkdown } from 'fark-study-engine/markdown';

const sheet = exportStudyMarkdown(cards, {
  title: 'Midterm Study Sheet',
  includeStats: true,
  collapsibleAnswers: true
});

const parsed = importStudyMarkdown(`
## Physics
- SI unit of force? :: Newton (N)
- Acceleration unit? :: m/s^2

## Chemistry
Q: Water formula?
A: H2O
`);
```

Supported Markdown input patterns:
- Headings (`#`, `##`, `###`) switch the current topic.
- Single-line `Question :: Answer` (with or without `-`, `*`, `+`, or numbered bullets).
- Multi-line `- **Q:** ...` / `  - **A:** ...`, `Q:` / `A:` pairs, and collapsible `<details><summary>...</summary>...</details>` answers generated by `exportStudyMarkdown`.

## Türkçe özet

- **Şeffaf aralık stratejileri (`./strategies`):** Tek bir gizli formülün herkes için en iyisi olduğunu iddia etmek yerine üç açık aralık ön ayarı sunar (`balanced`, `gentle`, `intensive`) ve `compareStrategies` ile aynı yanıt dizisinin farklı stratejilerde kaç güne yayıldığını yan yana karşılaştırır.
- **Markdown çalışma sayfaları (`./markdown`):** Desteyi konulara göre gruplanmış okunabilir Markdown'a (`exportStudyMarkdown`) aktarır; `## Konu`, `- Soru :: Yanıt` veya `Q:` / `A:` biçimindeki notları doğrudan FARK kartlarına dönüştürür (`importStudyMarkdown`).
