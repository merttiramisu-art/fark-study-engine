# Contributing / Katkı rehberi

Thank you for considering improvements to this learning utility. Contributions are welcome in Turkish or English.

1. Open an issue describing a bug or a focused enhancement before large changes.
2. Keep the engine dependency-free and offline by default.
3. Run `npm test` locally before opening a pull request.
4. Add tests for behavior changes and explain any scheduling or scoring adjustments.
5. Do not submit copied exam questions, textbooks, personal/student records, copyrighted content, secrets, or code from private projects.
6. Be respectful and constructive. Maintainers may decline changes that introduce tracking, opaque scoring, or unexpected paid dependencies.

This is an early-stage project. Merge and review times are not guaranteed.
